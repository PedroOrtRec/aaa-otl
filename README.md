# An Awesome Adventure - Ode to Leonor

Modpack basado en Minecraft 1.21.1 + NeoForge.

## Visual Stack Incluido

Se incluyeron los siguientes componentes para animaciones avanzadas de entidades:
- [EMF] Entity Model Features
- [ETF] Entity Texture Features
- Fresh Animations (resource pack)
- Fresh Animations: Extensions
- Fresh Animations: Player Extension
- Punchy!
- Hyper Punchy
- Fancy World Animations

## Nota de uso y distribucion (Fresh Animations)

El autor permite incluir el resource pack en modpacks y servidores.
Este pack integra Fresh Animations desde su fuente oficial mediante metadata packwiz.
No se debe redistribuir el pack como mirror o descarga separada fuera del flujo oficial.
